# Cadastro de Pets

Este projeto é uma aplicação web para cadastro de animais de estimação, permitindo que os usuários registrem informações sobre seus pets.

## Funcionalidades

- Cadastro de pets com informações como nome, apelido, raça e espécie.
- Visualização de todos os pets cadastrados com detalhes completos.
- Edição e exclusão de registros de pets e donos.

## Tecnologias Utilizadas

- **HTML**: Estruturação das páginas web.
- **CSS**: Estilização das interfaces.
- **Docker**: Containerização da aplicação.

## Estrutura do Projeto

O projeto contém os seguintes arquivos principais:

- `index.html`: Página principal com a lista de pets cadastrados.
- `pagina2.html`: Página para cadastro de novos pets.
- `pagina3.html`: Página para cadastro de donos.
- `styleindex.css`: Estilos para a página principal.
- `stylepagina2.css`: Estilos para a página de cadastro de pets.
- `stylepagina3.css`: Estilos para a página de cadastro de donos.
- `Dockerfile`: Configuração para criação do container Docker.
- `.dockerignore`: Arquivos e diretórios a serem ignorados pelo Docker.
